# 데이터 기반 철도 운행장애 유형화 및 피해 특성 분석

**Data-Driven Classification of Railway Operational Disruptions and Analysis of Their Operational Impacts: A Cluster Correspondence Analysis and Association Rule Mining Approach**

국내 철도 운행장애 사례를 대상으로 **군집대응분석(Cluster Correspondence Analysis, CCA)**과 **연관규칙분석(Association Rule Mining, ARM)**을 수행하고, 도출된 유형별 **열차 지연 및 금전적 피해 특성**을 비교한 연구의 분석 코드와 결과를 정리한 저장소입니다.

본 연구는 장애의 개별 원인만을 분석하는 접근에서 나아가, **철도 운영환경·열차 종류·장애 현황·발생 원인·발생 장소의 결합 양상**을 바탕으로 주요 운행장애 유형을 식별하고 유형별 관리 방향을 탐색합니다.

## 1. 연구 개요

- **연구 대상:** 한국교통안전공단 「국내 철도 사고 및 운행장애 발생 정보」의 국내 운행장애 사례
- **원자료 범위:** 2020년 1월 1일~2024년 12월 29일에 발생한 사건, 2024년 12월 31일 버전
- **자료 선별:** 전체 1,071건 중 운행장애 754건을 선별하고, 군집분석 변수의 결측 사례 15건을 제외하여 **739건** 분석
- **유형화:** 6개 범주형 변수를 사용한 CCA
- **유형 해석:** 군집별 범주 분포, 카이제곱 검정, 조정 표준화 잔차(ASR), 연관규칙분석
- **운행 영향 비교:** 지연 열차 수, 최대 지연 시간, 금전적 피해액

### 연구 질문

1. 국내 철도 운행장애는 운영환경과 발생 특성의 조합에 따라 어떤 유형으로 구분되는가?
2. 각 유형에서 상대적으로 두드러지는 특성과 범주 간 연관규칙은 무엇인가?
3. 유형별로 열차 지연 및 금전적 피해 특성은 어떻게 다른가?

## 2. 분석 자료와 변수

| 구분 | 변수 | 분석에서의 역할 |
|---|---|---|
| 유형화 | 철도구분 | 고속철도·일반철도·도시철도 등 운영환경 |
| 유형화 | 열차종류 | 여객열차·도시전동차 등 열차 특성 |
| 유형화 | 지연운행 현황 | 차량고장·신호장애·급전장애·무정차통과 등 장애 현황 |
| 유형화 | 지연운행 원인 | 시설장비결함·외부요인·취급(관리)부주의 등 |
| 유형화 | 근본원인별 원인 | 열차차량설비·신호제어설비·전철전력설비·환경요인 등 |
| 유형화 | 장소유형 A | 본선·역간·승강장·역 구내 선로 등 |
| 유형 해석 | 근본원인별 그룹 | 기술적·외적·인적 요인 |
| 운행 영향 비교 | 합계 지연 열차 수 | 장애 사건에 관련된 지연 열차 수 |
| 운행 영향 비교 | 합계 최대 지연 시간(분) | 사건별 최대 지연 시간 관련 지표 |
| 피해 비교 | 총 피해액(백만원) | 기록된 금전적 피해 규모 |

범주명 표기 정비, 희소 범주 통합, 결측 처리에 관한 세부 사항은 [분석 과정](docs/analysis-process.md)을 참고하세요.

## 3. 분석 절차

1. **자료 선별 및 전처리:** 운행장애 754건 선별 → 범주 정비 및 결측 제거 → 최종 739건.
2. **군집대응분석:** 군집 수(`K`)와 차원 수(`d`)를 달리한 후보모형을 비교하고, 내부 타당도·부트스트랩 안정성·해석 가능성을 종합적으로 검토.
3. **군집 특성 해석:** 군집별 범주 분포와 조정 표준화 잔차(ASR)를 이용하여 대표 특성을 확인.
4. **연관규칙분석:** 군집별로 함께 나타나는 범주 조합을 탐색.
5. **운행 영향 및 피해 비교:** 지연 열차 수, 최대 지연 시간, 총 피해액을 유형별로 비교.

**최종 CCA 모형 설정:** `K=6`, `d=5`, `nstart=100`, `seed=1234`.

연관규칙분석에는 **최소 지지도 0.20, 최소 신뢰도 0.60, 최소 향상도 1.20**, 규칙 항목 수 최대 3개를 적용했습니다. 군집별 규칙은 향상도·신뢰도·지지도 순으로 정렬했습니다.

> CCA는 범주형 특성에 기초한 **유형 탐색** 방법이며, ARM에서 확인한 연관규칙은 **동시 출현 관계**를 나타냅니다. 분석 결과만으로 장애 발생의 인과관계를 추론하지 않습니다.

## 4. 주요 연구 결과

### 4.1 운행장애 유형

| 군집 | 사례 수 | 비중 | 유형명 |
|---:|---:|---:|---|
| 1 | 337 | 45.60% | 여객열차 및 차량설비 고장형 |
| 2 | 132 | 17.86% | 도시 전동차 및 복합 설비 장애형 |
| 3 | 97 | 13.13% | 외부 환경 요인형 |
| 4 | 90 | 12.18% | 신호 제어 설비 장애형 |
| 5 | 48 | 6.50% | 무정차 통과 및 운전 취급 부주의형 |
| 6 | 35 | 4.74% | 전철 전력 설비 및 급전 장애형 |
| **합계** | **739** | **100.00%** | |

유형명은 자동으로 생성된 라벨이 아니라, **군집별 범주 분포와 조정 표준화 잔차를 바탕으로 연구자가 부여한 해석용 명칭**입니다.

### 4.2 유형별 연관 특성

연관규칙분석 결과, **군집 1에서는 설정 기준을 충족하는 규칙이 도출되지 않았으며**, 나머지 5개 군집의 주요 규칙을 선별하여 논문에 총 **15개 규칙**을 제시했습니다.

- **군집 2:** 도시 전동차·차량 고장·열차 차량 설비의 동시 출현
- **군집 3:** 도시 전동차·도시철도·환경 요인의 결합
- **군집 4:** 신호 장애·신호 제어 설비·역 구내 선로 관련 조합
- **군집 5:** 무정차 통과·기관사(운전자)·역 승강장의 동시 출현
- **군집 6:** 전철 전력 설비·시설 및 장비 결함 관련 조합

규칙별 지지도, 신뢰도, 향상도와 전체 분석 결과는 [분석 결과](docs/results.md)를 참고하세요.

### 4.3 지연 및 피해 특성

- **발생 빈도:** 군집 1(45.60%)이 가장 많았으나, 지연 열차 수의 중앙값은 1대였습니다.
- **지연 열차 수:** 중앙값은 군집 4가 **6대**로 가장 높았고, 군집 6이 **5대**였습니다.
- **최대 지연 시간:** 중앙값은 군집 6이 **41분**으로 가장 높았으며, 군집 1은 **38분**이었습니다.
- **금전적 피해 기록 비율:** 군집 1이 **86.6%**로 가장 높았습니다.
- **피해액 중앙값:** **금전적 피해가 기록된 사례만을 대상으로** 군집 4가 **4.604백만원**, 군집 6이 **4.029백만원**이었습니다.

이러한 결과는 **장애 발생 빈도가 높다고 해서 사건별 지연·피해 규모까지 반드시 큰 것은 아님**을 보여줍니다. 피해액의 기록 여부와 결측 상태를 고려하여 지표를 해석해야 합니다.

## 5. 연구의 활용 방향과 해석 시 유의사항

연구에서는 유형별 특성에 따라 다음과 같은 **관리 방향을 제안**합니다.

- **빈발형 장애(군집 1·2):** 차량·설비 정비 이력에 기초한 예방정비 및 부서 간 정보 연계
- **지연 영향형 장애(군집 4·6):** 신호·전력 설비 장애 발생 시 관제·복구·운행 조정 절차 점검
- **상황 의존형 장애(군집 3·5):** 외부 환경 모니터링과 운전 취급·정차 확인 절차 개선

이러한 관리 방향은 **분석 결과에 근거한 제안**이며, 실제 현장 적용 효과를 실증적으로 검증한 결과는 아닙니다. 또한 유형별 지연·피해 지표는 기술통계 비교이므로 군집 간 차이에 대한 인과적 해석을 피해야 합니다.

## 7. 분석 재현

**필요 환경:** Python 3.11 이상, R, R 패키지 `clustrd`.

Python 환경 설정 및 결과표 재생성:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt

python -m analysis.cluster_profiles
python -m analysis.impact_summary
python -m analysis.association_rules
python -m pytest -q
```

CCA 모형부터 재적합하는 경우:

```r
install.packages("clustrd")
```

```bash
Rscript analysis/fit_clusca.R
```

> **재현성 안내:** 위 명령어와 디렉터리 경로는 제공된 저장소 구성 설명을 기준으로 작성했습니다. 실제 저장소에서의 실행 성공 여부는 별도로 검증되지 않았습니다. 원자료 접근 권한과 파일 구성에 따라 일부 단계가 제한될 수 있습니다.
